# Browser impersonation for yt-dlp. YouTube's caption URLs are marked
# "impersonate" by yt-dlp, i.e. fetched with a real browser's TLS/HTTP
# fingerprint via curl_cffi. The droplet sat at curl_cffi 0.5.10 (2023),
# whose newest target is Chrome 110 -- every caption request announced a
# three-year-old browser, found 2026-09-30 while chasing caption 429s.
# Floor matches yt-dlp's own pinned version (its `pin-curl-cffi` extra);
# the cap is yt-dlp's own supported ceiling (<0.17 as of 2026.09.27).
# A floor is needed: yt-dlp's plain requirement (>=0.5.10) is already
# "satisfied" by the stale copy, so nothing else would ever upgrade it.
curl-cffi>=0.16.0,<0.17

# YouTube PO-token plugin (bgutil-ytdlp-pot-provider) is deliberately NOT
# pinned here. It's paired with the separately-deployed bgutil.service HTTP
# server on this same droplet, and refuses to run at all if its major
# version doesn't match the server's -- a static pin here drifted stale
# within weeks (confirmed 2026-09-29: droplet's plugin sat at 1.3.1 against
# the server's 2.0.0 and broke every YouTube grab with "Plugin and script
# major versions are mismatched") because nothing here tracks the server's
# own version. tools/sync_bgutil_plugin.py owns installing/upgrading this
# package instead -- it queries the server's live /ping for its real
# version and installs a matching release every time it runs (wired into
# basiq-ytdlp-update.service, see tools/build/deploy/).

# Live-capture transcript streaming: feeds a second, audio-only ffmpeg
# process to Deepgram's real-time API alongside a live capture, for the
# live-clip transcript feed. Only imported/used when DEEPGRAM_API_KEY is set.
websocket-client>=1.7.0

# Generic live-stream resolution: yt-dlp only knows sites with a dedicated
# extractor. For everything else (e.g. CBS News, ABC News -- major network
# live pages with no yt-dlp extractor at all), a headless browser loads the
# page and watches its own network traffic for the manifest URL the site's
# own player uses. Degrades gracefully -- if this isn't installed, live
# capture just falls back to yt-dlp-only coverage.
# After installing, also run: playwright install firefox
# (basiq_agent.py's generic live resolver uses Firefox, not Chromium, as of
# 2026-09-24 -- Akamai Bot Manager challenged automated Chromium on a real
# login-gated source. `playwright install chromium` alone is no longer
# sufficient for that path.)
playwright>=1.40.0
